# Global Death Penalty Status Maps

## Overview

This project visualizes global changes in death penalty policy between 1990 and 2022.

Using country-level data and spatial mapping tools in R, I created side-by-side choropleth maps showing the legal status of the death penalty around the world. The visualization highlights the substantial global trend toward abolition over the past three decades.

## Research Question

How has the global legal status of the death penalty changed between 1990 and 2022?

## Methods

- Data cleaning and country name standardization
- Spatial data joins using country shapefiles
- Geographic visualization with ggplot2 and sf
- Comparative policy analysis

## Tools Used

- R
- tidyverse
- ggplot2
- sf
- rnaturalearth
- patchwork

## Dataset

Capital Punishment Database (CPDP), 2024

## Key Finding

Many countries that retained the death penalty in 1990 had abolished it or significantly restricted its use by 2022, illustrating a broader international trend toward abolition.
